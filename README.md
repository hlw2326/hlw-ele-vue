# @hlw-ele/vue

`@hlw-ele/vue` 是为 Electron 渲染端量身定做的 Vue 3 业务组件及 Composables 工具库。

## 安装

```bash
pnpm add @hlw-ele/vue
```

## 包含的组件

- **Avatar / Button / Drawer / Form / Modal**：一系列定制化 UI 组件。
- **hlw-logs**：日志展示与清除组件。
- **hlw-upsert**：更新与添加表单逻辑封装。
- **hlw-version-input**：版本输入和选择组件。
